# Лаба 1: MLP на MNIST — что происходит и как отвечать

Смысл простыми словами: собираем самую простую нейросеть (многослойный перцептрон), которая смотрит на картинку цифры 28x28 и угадывает, что это за цифра от 0 до 9. Учим ее, проверяем точность, крутим ручки (dropout, batch) и смотрим, что меняется. Все 7 пунктов методички закрыты в `lab1_mlp_mnist.ipynb`.

## По пунктам — что говорить

**П.1 Данные:** `keras.datasets.mnist.load_data()` → `60000 картинок 28x28 для обучения / 10000 для теста`. Показываем по 1 примеру на каждую цифру `0-9`. Предобработка: делим на 255 (яркость `0-255` → `0-1`, иначе градиенты рвутся) и вытягиваем картинку в вектор длины `784` (`reshape(-1,784)`) — MLP не понимает двумерные картинки, ему нужен плоский вектор.

**П.2 Builder `build_mlp(hidden, dropout)`:**

```python
Input(784) -> [Dense(h, relu) + Dropout(d)] x N -> Dense(10, softmax)
compile(loss=SparseCategoricalCrossentropy, optimizer=adam, metrics=acc)
```

`hidden=(128,)` или `(128,64)`. `relu` на скрытых — не дает градиенту затухать, считается быстро; `softmax` на выходе — превращает 10 чисел в вероятности (сумма = 1). `Dropout` весов не добавляет, только маскирует нейроны во время обучения. `count_params()` — ручной подсчет весов, обязан совпасть с `model.count_params()`.

**П.3 База: `(128,), dropout=0.2, batch=128, 15 эпох, validation_split=0.2`:**
Параметры: `(784+1)*128 + (128+1)*10 = 101770` (`+1` — это bias, сдвиг каждого нейрона). Кривые: `train acc 0.8771 -> 0.9865`, `val 0.9415 -> 0.9788`, `val_loss 0.2077 -> 0.0756`. Отвечать: обе кривые растут/падают гладко, зазора между train и val нет — переобучения нет, `dropout=0.2` держит.

**П.4 Тест:** `evaluate: loss=0.0684 acc=0.9803` — на новых данных, которых сеть не видела, угадывает 98 из 100. `confusion_matrix` дает `trace/sum = 0.9803`, разница с evaluate `9e-09` — доказывает, что метрика посчитана честно двумя способами. Ошибки — похожие пары: `4<->9, 3<->5/8, 7<->9/2`. Показываем табличку `true -> pred` по 1 ошибке на класс.

## Контрольные — готовые ответы

**1. Формальный нейрон:** адаптивный сумматор $s=w^Tx$ (неоднородный: $s=w_0+\sum w_ix_i$) + активация $y=f(s)$ + точка ветвления (раздача выхода всем дальше). Требования к $f$: монотонно возрастает, производная есть почти везде, считается через саму $f$ (нужно для backprop). Виды: рациональная / логистическая сигмоида $1/(1+e^{-S})$, `ReLU: max(0,s)`, `LeakyReLU: s / 0.01s`.

**2. Архитектуры:** слоистые — сигнал идет слой за слоем: $S_j^{(n)}=\sum_{i} w_{ij}^{(n)}y_i^{(n-1)},\; y_j^{(n)}=f(S_j^{(n)})$, каждый выход слоя `i` идет на все входы `i+1`. Частный случай — 3-слойная (вход/скрытый/выход). Полносвязные — каждый со всеми включая себя, работают тактами: $y_j(t)=f(\sum w_{ij}y_i(t-1))$. При фиксированных `k` тактах это то же, что `k`-слойная; при неограниченных — так умеет только полносвязная. Рекуррентная = любая с обратной связью.

**3. Теоремы:** Колмогоров-Арнольд (1957) — любая непрерывная на кубе = $\sum_{q=1}^{2n+1}h_q[\sum_p \varphi_q(x_p)]$, т.е. точное представление 3-слойной сетью; проблема — найти сами $h,\varphi$. Вейерштрасс (1885) — полиномы плотны в непрерывных на компакте по равномерной норме (приблизить можно сколь угодно точно в каждой точке). Стоун (1935) — плотна любая замкнутая алгебра с единицей, разделяющая точки. Применимость к НС: 1) линейная комбинация — новый слой с весами $\alpha$, произведение — через $F_1F_2=\frac12((F_1+F_2)^2-F_1^2-F_2^2)$ + квадратичная активация; 2) единица — вес 1, смещение 0, тождественная $f$; 3) разделение — $f(x)=(a-b)^Tx-\frac12(a+b)^T(a-b)$, $f(a)-f(b)\ne 0$.

**4. Backprop (однородная, логистическая):** 1) веса случайно из $[-1,1]$; 2) прямой проход по формуле (1); 3) ошибки с выхода назад: $g_j^{(N)}=y_j^{(N)}(1-y_j^{(N)})(d_j-y_j^{(N)})$, $g_j^{(n)}=y_j^{(n)}(1-y_j^{(n)})\sum_i g_i^{(n+1)}w_{ji}^{(n+1)}$; 4) шаг $\Delta w_{ij}^{(n)}=\rho\, g_i^{(n)}y_j^{(n-1)}$; 5) периодический тест. Образцы подавать в случайном порядке, иначе сеть подстроится под последние и забудет первые.

## Частые вопросы препода — короткие ответы

### Зачем нужны и loss, и accuracy одновременно?

`loss` — учит, `acc` — отчитывается.

`loss = SparseCategoricalCrossentropy` — непрерывная, дифференцируемая, ее минимизирует `adam`. Чувствительна к уверенности: угадал с `p=0.51` и с `p=0.99` — `acc` одинаковый (1), а `loss` отличается в разы. Без нее градиента нет: `acc` — ступенчатая функция, производная почти везде ноль, по ней учиться нельзя.

`acc = mean(argmax==y)` — дискретная, это критерий качества из методички. Нужна человеку: `0.9803` понятно, `0.0684` — нет. Не видит калибровки.

Почему оба на кривых: они расходятся и этим палят проблемы. Примеры из лабы: `batch=128` лучший по `val_loss 0.0784`, но по `val_acc 0.9765` хуже `batch=64 (0.9773)` — увереннее, но не точнее. `dropout=0`: `train_loss 0.0144` в ноль, а `val_loss 0.0878` худший — по одному `train acc 0.9981` решили бы, что все отлично, а связка `train loss + val loss` показывает переобучение. Тройка `evaluate loss + acc + confusion matrix` — сверка, что сошлось и посчитано честно.

Правило: `val_loss` — для сравнения моделей и ранней остановки, `val_acc / confusion` — для итогового качества.

### Что такое dropout и чем он отличается от Dense?

Разные сущности: `Dense` — учит, `Dropout` — мешает зубрить.

`Dense(h)` — обучаемый слой, формула `y=f(Wx+b)`, хранит веса `(fan_in+1)*fan_out`. В базе `784->128` это `100480` чисел. Работает всегда — и в обучении, и в тесте.

`Dropout(rate)` — необучаемый слой, параметров 0. В обучении случайно обнуляет долю `rate` нейронов и умножает остаток на `1/(1-rate)` (чтобы средний масштаб не уплыл); в тесте — просто провод, ничего не делает. Смысл: запрещает нейронам сговариваться («ты учишь ус, я — хвост»), заставляет дублировать признаки. Математически — обучение ансамбля из $2^h$ подсетей с общими весами.

Цифры лабы при `batch=128`: `d=0 → train 0.0144 / val 0.0878` (зазубрил), `d=0.2 → 0.0427/0.0756` (лучший val), `d=0.3 → 0.0596/0.0828` (задушили). Оптимум `0.1-0.2`.

### Dense, dense_1 и dropout — вместе или отдельно?

Вместе, строго друг за другом: `Input(784) -> Dense(128,relu) -> Dropout(0.2) -> Dense(10,softmax)`.

- `dense` — первый (скрытый): `(B,784)->(B,128)`, `100480` параметров.
- `dropout` — между ними: `(B,128)->(B,128)`, 0 параметров, активен только в `fit`.
- `dense_1` — второй (выходной): `(B,128)->(B,10)`, `1290` параметров.

`dense / dense_1` — просто автоимена Keras (первый, второй), не два режима. Сигнал всегда идет через все три слоя, варианта «или dense, или dropout» нет.

## Функции — подробно и просто

Сквозная картинка размерностей: картинка `(28,28)` из целых яркостей `0-255` → вектор `(784,)` из дробей `0-1` → батч `(B,784)` → вероятности `(B,10)` → номер цифры. Метка одного объекта — просто число `0-9`, пачка меток — вектор `(N,)`.

### 1. Свои функции

**`build_mlp(hidden=(128,), dropout=0.2, input_dim=784, n_classes=10)` → готовая модель**
Простыми словами: конструктор сети. Говоришь «хочу 1 слой по 128» — получаешь собранную и настроенную на обучение модель.

- Что на входе: `hidden` — кортеж, сколько нейронов в каждом скрытом слое. `(128,)` — один слой, `(96,64)` — два. `dropout` — доля отключаемых нейронов (`0` — без dropout). Остальное обычно не трогаем.
- Что внутри: `Input` → для каждого `h` пара `Dense(h, relu) + Dropout` → финальный `Dense(10, softmax)` → `compile` (настройка: что минимизировать, чем шагать, что мерить).
- Что на выходе: объект модели. Веса вначале случайные (`GlorotUniform`), bias — нули.
- Что сказать преподу: «relu скрытым, softmax выходному; dropout только маскирует, весов не добавляет».

**`count_params(hidden, input_dim=784, n_classes=10)` → число (int)**
Простыми словами: калькулятор «сколько весов в сети» без самой сети, ручка для проверки п.7.

- Формула: для каждого `Dense` считаем `(входов+1)*выходов`, где `+1` — bias (по одному сдвигу на нейрон), и складываем.
- Примеры, которые надо помнить: `(128,)` → `101770`; `(100,)` → `79510`; `(96,64)` → `82218`. Разбор первого: `Dense(784->128)` = `784*128 + 128 = 100480`, `Dense(128->10)` = `128*10 + 10 = 1290`, сумма `101770`.
- Зачем: `assert model.count_params() == count_params(...)` — доказывает, что аналитика из п.7 верна.

**`_mlp_model(hidden=(128,), dropout=0.2)` → модель**
Простыми словами: переходник для `GridSearchCV`. Поиск по сетке умеет крутить только аргументы по имени, поэтому нужна функция, у которой аргумент называется ровно `hidden` (тогда в сетке он `model__hidden`).

- Вход/выход — как у `build_mlp`, просто вызывает его внутри.

**`make_clf(epochs=10, batch_size=128)` → sklearn-обертка**
Простыми словами: заворачивает Keras-модель в фантик, понятный sklearn, чтобы `GridSearchCV` мог ее учить и оценивать как обычный классификатор.

- Что фиксирует внутри: `loss=SparseCategoricalCrossentropy, optimizer=adam, metrics=acc, dropout=0.2` — их не перебираем.
- Что перебирает сетка: `epochs` и `batch_size` (ключи без префикса `model__`, потому что это аргументы самой обертки, а не строителя сети).

### 2. Загрузка данных

**`keras.datasets.mnist.load_data()` → две пары (картинки, метки)**

- Вход: ничего (первый раз скачивает ~11 МБ).
- Выход: обучение `(60000,28,28) + (60000,)`, тест `(10000,28,28) + (10000,)`. Картинки — целые `uint8 0-255`, метки — целые `0-9`.
- Дальше руками: `astype('float32')/255.0` (дроби `0-1`, иначе adam прыгает) и `reshape(-1,784)` (плоский вектор, иначе Dense не примет).

### 3. Слои и сборка модели

**`layers.Input(shape=(784,))` — входная розетка**

- Вход: описание одного объекта без батча.
- Выход: тензор `(None,784)`, где `None` — место под размер батча (любой).

**`layers.Dense(h, activation=...)` — единственный обучаемый слой**
Простыми словами: пачка нейронов, каждый смотрит на все входы сразу. Умножить, сложить, добавить сдвиг, прогнать через `relu/softmax`.

- Вход `(B,fan_in)` → выход `(B,fan_out)`. Пример: `(128,784)`? Нет — батч первым: `(128 картинок, 784)` → `(128,128)`.
- Веса: матрица `(fan_in,fan_out)` + вектор `(fan_out,)`. Поэтому `784->128` = `100480` чисел.
- Почему две активации: `relu = max(0,x)` скрытым (дешево, градиент не тухнет), `softmax` выходному (10 чисел → вероятности, сумма 1, можно брать `argmax`).

**`layers.Dropout(rate)` — шумелка против зубрежки**

- Вход и выход одной формы, например `(B,128) -> (B,128)`. Весов 0.
- В обучении: каждый нейрон с вероятностью `rate` обнуляется, остальные умножаются на `1/(1-rate)`. В тесте: ничего не делает.
- Интуиция: каждый батч учится случайная подсеть, нейроны не могут положиться друг на друга.

**`Sequential / add / compile` — сборка и настройка**

- `Sequential([...])` — просто стопка слоев по порядку, сигнал течет сверху вниз.
- `compile(loss, optimizer, metrics)`: `SparseCategoricalCrossentropy` — штраф за неуверенность (принимает целые метки `0-9`, one-hot не нужен); `adam` — умный шаг градиента с адаптацией; `acc` — что показывать человеку.

**`model.summary() / model.count_params()` — паспорт модели**

- `summary` — таблица: слои, формы выходов, число параметров. У базы `Trainable 101770`. После `fit` в таблице еще `Optimizer params 203542` — это моменты adam (по 2 числа на вес), не пугаться.
- `count_params` — просто число, сверяем с `count_params()` из п.7.

### 4. Обучение и оценка

**`model.fit(X, y, epochs, batch_size, validation_split)` → история обучения**
Простыми словами: сама учеба. Показываем картинки, считаем ошибку, двигаем веса.

- Вход: `X (60000,784)`, `y (60000,)`. `validation_split=0.2` отрезает хвост `12000` картинок на проверку, учимся на `48000`. При `batch=128` шагов на эпоху `48000/128 = 375` — эту цифру видно в логе (`375/375`).
- `epochs=15` — сколько раз пройти весь набор. `verbose=2` — строка на эпоху, `verbose=0` — тихо (для свипов).
- Выход: `History.history` — четыре списка длины 15: `loss, acc` (по обучению) и `val_loss, val_acc` (по отложенным). Их и рисуем.
- Как читать: обе `loss` падают — учится; `train` падает, а `val` встал/растет — переобучение; обе стоят — недообучение или большой dropout.

**`tf.keras.backend.clear_session() + seed(42)` — честный рестарт**

- Что: сносит старый граф и фиксирует случайность перед каждым прогоном свипа.
- Зачем: без этого сравнение `dropout=0.1 vs 0.2` нечестное — у них были бы разные стартовые веса.

**`model.evaluate(X, y)` → два числа `(loss, acc)`**

- Вход: тест `(10000,784) + (10000,)`, которых сеть не видела.
- Выход: у базы `loss=0.0684, acc=0.9803`. Dropout внутри выключен, т.е. меряем боевую сеть целиком.
- Что сказать: «потеря для оптимизации, точность — критерий из методички».

**`model.predict(X)` → вероятности, затем `argmax` → классы**

- Вход `(10000,784)` → выход `(10000,10)` вероятностей. `np.argmax(..., axis=1)` берет номер максимальной колонки → вектор `(10000,)` предсказаний.
- Пример строки: `[0.01, 0.02, ..., 0.9, ...]` → `2`.

### 5. Метрики и картинки

**`sklearn.metrics.confusion_matrix(y_true, y_pred)` → таблица `10x10`**
Простыми словами: кто кого с кем путает. Строка — правда, столбец — ответ сети, диагональ — правильные.

- Вход: два вектора по `(10000,)`. Выход: матрица `(10,10)`.
- Качество из нее: `trace (сумма диагонали) / sum (все)` = доля верных. У нас `0.9803`, совпадает с `evaluate` до `9e-09` — так и надо отвечать на вопрос «сравнить».

**Поиск ошибок: `np.flatnonzero((y_test==t) & (pred!=y_test))[0]`**

- Что: «дай первый индекс, где правда `t`, а сеть ошиблась». Маски — векторы `(10000,)` из `True/False`, `&` — совпадение обоих условий.
- Дальше `imshow(x.reshape(28,28))` — разворачиваем вектор обратно в картинку и показываем в сетке `2x5` с заголовком `true -> pred`.

**`plt.plot / subplots / legend / grid` — кривые обучения**

- Рисуем `loss` и `acc` от эпохи, отдельно train и val. По расхождению читаем переобучение, по дрожанию — маленький batch, по наклону — скорость сходимости.

### 6. Подбор гиперпараметров

**`GridSearchCV(estimator, param_grid, cv=3)` + `.fit(X, y)`**
Простыми словами: робот-переборщик. Говоришь «попробуй нейроны 64/128/256 и batch 32/64/128» — он учит все комбинации по 3 раза на разных кусках данных и выбирает лучшую в среднем.

- Вход: весь train `(60000,784)`. Сетка `9 комбинаций x 3 фолда = 27 обучений` по 10 эпох.
- Ключ с `model__` (`model__hidden`) — крутит аргумент строителя сети; ключ без префикса (`batch_size`) — аргумент самой обертки `KerasClassifier`.
- Выход: `best_params_ = {batch_size: 32, hidden: (256,)}`, `best_score_ = 0.9758` — средний val-acc по фолдам. `dropout` и `epochs` зафиксированы — так требует п.6.
